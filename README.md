# Arcanova · 第一個可玩原型

這是依據 v0.3 設定建立的前端垂直切片：第一大陸「曙光邊境」的探索、回合制遭遇戰、升級、世界 Boss 非同步貢獻，以及世界公告。

## 開啟方式

直接以瀏覽器開啟 `index.html`。不需安裝套件或啟動伺服器。

## 本版本包含

- 探索會依角色等級動態抽取一種遭遇，並進入速度概念下的單人回合制戰鬥。
- 斬擊、防禦、失敗撤退、休整與生命管理。
- 金幣、經驗、等級與角色屬性成長；Lv.5 會出現職業系統開放提示。
- 第一大陸世界 Boss「灰燼巨像」的獨立挑戰、傷害貢獻與公告；原型從 100% HP 開始，沒有虛構其他玩家進度。
- Lv.5 生活職業抉擇（獵人、鍊金師、鐵匠、學者）。
- 種子化裝備掉落、背包清單、能力加成，以及此瀏覽器內的手動儲存／重設。
- 適合桌面和手機寬度的無美術資源介面。

### 新增：怪物分級 / 詞綴 / Boss機制 / 裝備詞綴

- **威脅分級**：怪物模板池擴充為 10 種，並依角色等級隨機套用「普通／精英／稀有／史詩」4 個分級（對應設計文檔的 5-tier 架構，第 5 級「世界」保留給世界 Boss），分級會放大怪物的生命與攻擊。
- **怪物詞綴（8 種）**：灼熱、劇毒、堅硬、迅捷、汲取、狂暴、守護、反射。精英以上的怪物有機率帶 1-2 個詞綴，各自有實際戰鬥效果（例如灼熱／劇毒造成持續傷害、堅硬降低你造成的傷害、迅捷有機率追加攻擊、狂暴在敵人瀕死時攻擊力提升、守護會不定期產生護盾、反射會反彈你的攻擊傷害）。戰鬥視窗會即時顯示敵人分級與詞綴標籤。
- **世界 Boss 機制模組庫**：每次挑戰灰燼巨像，會從同一組詞綴池中隨機抽出 2 個套用在 Boss 身上，作為簡化版的「機制模組庫」，讓每次攻略都需要應對不同組合，而不必為每個世界 Boss 手刻專屬機制。
- **裝備詞綴**：稀有度擴充為「普通／精良／稀有／史詩／傳說」5 階，精良以上有機率額外帶 1-2 個詞綴（暴擊率、生命偷取、格擋、最大生命、戰利品機率），效果會即時套用到角色戰鬥屬性上，並顯示在行囊與英雄面板。
- **旅途圖鑑**：新增「圖鑑」頁籤，會依你實際遭遇過的分級／詞綴／怪物動態記錄，作為輕量的收集要素。

這些系統目前都是前端隨機生成、沒有伺服器同步；世界 Boss 的機制組合每次挑戰都會重新抽取，僅代表當次的挑戰變化，並非全服共享的固定機制。

### 新增：探索事件系統

原本「踏入荒原」只會直接進入戰鬥，內容略顯單調。現在改為一套加權事件系統，符合設計文檔「日常探索沿用隨機事件系統」的方向：

- **遭遇戰**（機率最高）：沿用怪物分級／詞綴系統。
- **尋寶**：直接獲得金幣，並有機率額外掉落裝備。
- **旅途見聞**：純文字的世界觀小片段（會記錄進圖鑑「旅途見聞」欄位），並給予少量經驗，用來在戰鬥之間補充 Arcanova 的世界觀線索。
- **意外事故**：踩到陷阱、灼傷等小型負面事件，依防禦力減傷後扣除少量生命，增加緊張感。
- **抉擇事件**（彈出選擇視窗）：封印的箱子、受傷的旅人、古老的祭壇、神秘行商、岔路，共 5 種情境，每種提供 2 個選項、各自有不同的風險／報酬（例如冒險撬鎖有機率獲得更好戰利品但可能反噬扣血；深入岔路的裂谷會直接觸發一場等級較高的戰鬥）。

事件文字與數值集中寫在 `game.js` 的 `TREASURE_EVENTS` / `LORE_EVENTS` / `HAZARD_EVENTS` / `CHOICE_EVENTS` 陣列，目前共 50 種（尋寶 15、旅途見聞 15、意外事故 10、抉擇事件 10），之後要新增更多探索內容，直接在對應陣列裡加項目即可，不需要改動觸發邏輯。

## 下一個里程碑：伺服器化

目前是純前端原型，進度會暫存在本機瀏覽器；這只適合展示，不能作為正式角色資料。為對齊設定文檔，下一步應建立 API 與資料庫，將下列狀態綁定 `userId`：

| 範疇 | 主要資料 |
| --- | --- |
| 使用者 | `id`, `email`, `passwordHash`, `createdAt` |
| 英雄 | `userId`, 等級、經驗、屬性、隊伍、背包 |
| 裝備 | `ownerId`, `seed`, 稀有度、詞綴、交易狀態 |
| 世界進度 | 當前大陸、Boss 最大/當前 HP、最後回復時間 |
| Boss 貢獻 | `userId`, `continentId`, 累積傷害、獎勵狀態 |
| 公告 | 類型、內文、門檻、發送時間 |

建議技術組合是 **Node.js + TypeScript + PostgreSQL**。世界 Boss 的扣血與大陸解鎖必須由單一資料庫交易處理，避免同時結算造成血量低於零或重複開放。

## 建議先定案的數值

- 世界 Boss 基礎血量：`500,000 × 大陸難度係數 × (0.8 + 0.35 × 活躍玩家數)`；每日重算「活躍玩家」後，只調整下一輪 Boss 的最大血量，避免中途跳血。
- 自然回復：每小時最大生命的 `0.3%`，上限不超過最大生命；這會維持壓力但不會讓小型社群挫折。
- 市集：第一大陸即開放補給商人；玩家上架 48 小時，成交抽取 `5%`（最低 1 金幣）。
- 兩個補足元素：**雷霆**（天空文明）與 **星辰**（星界文明），能自然對應第 7 與第 11 大陸。
